# Session 02 — Git et GitHub

## Objectifs
- Vérifier la configuration de Git.
- Gérer le projet avec Git et GitHub.
- Créer des commits clairs et séparés.
- Ajouter la page `/a-propos`.
- Documenter le projet dans `README.md`.
- Publier le projet sur GitHub.

## Commandes Git utiles

```bash
git status
git add <fichier>
git commit -m "Message explicite"
git log --oneline
git push origin main
```

## Bonnes pratiques
- Faire des commits petits et cohérents.
- Utiliser des messages explicites en français.
- Vérifier `git status` avant chaque commit.
- Ne jamais publier le fichier `.env`.

## Page créée
La page `/a-propos` affiche le nom de l'auteur, le groupe et des liens vers les autres pages du projet.
